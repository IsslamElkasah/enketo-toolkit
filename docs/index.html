Enketo Toolkit

A bookmark that helps you rescue saved drafts in Enketo web forms. Set it up once, then use it whenever a draft gets stuck.

What it does

Rename/FixRepairs a draft that won't send because of an error like 409 or "already exists", and lets you rename it.
Save a copyDownloads a copy of a draft to your device, so the answers are never lost.
DeleteRemoves one draft from this form only. Drafts on your other forms are left alone.
Choose a saved draftFills a new, empty copy of the form from a draft you saved.

1. Copy the bookmark code

If the button doesn't work, tap inside the box, select all, and copy.

2. Create the bookmark

  1. In Chrome, tap ⋮ at the top right, then tap the star ☆ to bookmark this page.
  2. Tap Edit on the message that appears at the bottom. If you miss it, go to ⋮ › Bookmarks, find this page, and choose Edit.
  3. Change the name to Enketo Toolkit.
  4. In the URL box, delete everything and paste the code you copied.
  5. Go back to save.

Enketo Toolkit

Or use the Android method: bookmark this page, edit it, name it Enketo Toolkit, and paste the code into the URL.

3. Use it

  1. Open the Enketo form that has the problem draft.
  2. Android: tap the address bar, type Enketo, and tap the Enketo Toolkit suggestion with the star icon.
    Computer: click Enketo Toolkit on the bookmarks bar.
  3. A panel lists the drafts saved for this form.
  4. Tap Save a copy first, to keep a backup of the draft.
  5. Tap Rename/Fix, type a name, and confirm. The page reloads.
  6. Open the draft and submit it. If it was already waiting to upload, it sends by itself after the reload.

4. If the draft is still stuck

  1. Make sure you used Save a copy on the draft (step 3).
  2. Open the toolkit and tap Delete on the stuck draft, then confirm.
  3. Open a new, empty copy of the form.
  4. Open the toolkit and tap Choose a saved draft, then pick the file you saved. On Android it is in Downloads.
  5. Check the answers, fill in anything listed as not restored, and submit.

Photos and file uploads are not restored. Calculated fields are skipped and recalculate on their own. If it still won't send, send the saved file to your administrator.

Problems?

Nothing happens when I tap the bookmark
Make sure you tapped the suggestion with the star icon, not a search result. Check that the bookmark's URL starts with javascript:. Some phones remove it when pasting; if so, type it back in.
"Enketo Toolkit could not load"
Check your internet connection and try again.
"Open an Enketo form first"
The bookmark only works on an open Enketo form page.
"No saved drafts for this form"
Drafts belong to one form. Open the form where you saved the draft.
The saved draft is greyed out when restoring
In the file picker, open Downloads from the menu, or choose to show all files.
A draft saved on my phone, can I restore it on a computer?
Yes. Saved drafts are the same format in the bookmark and the browser extension.
